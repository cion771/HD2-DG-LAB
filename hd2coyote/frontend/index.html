更新与回滚

  1. 停止检测、保持未武装，并备份本机配置目录。
  2. 从 GitHub Releases 下载并核对 SHA256；关闭旧版后再替换桌面 EXE。
  3. 只有发布说明明确要求更新游戏桥时，才重新导入桥 ZIP 并重启游戏。
  4. 需要回滚时，同时恢复上一版 EXE、对应桥 ZIP 与配置备份；不要混用不同版本的桥 profile。

更新器不会自动覆盖文件。完整步骤与兼容性说明见仓库 docs/UPGRADE.md。
