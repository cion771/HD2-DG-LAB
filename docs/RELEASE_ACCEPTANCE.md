# 发布验收矩阵

本矩阵用于每个 HD2-DG-LAB Release 的发布前验收。它把**能自动证明的事实**和**必须在真实环境中人工确认的行为**分开，避免把“单元测试通过”写成“游戏/设备实测通过”。

## 结论规则

- `AUT-*` 是自动门禁。任何一项 `FAIL` 都阻断打包、标签和 Release。
- `MAN-*` 是人工验收。必须记录版本、环境、结果和脱敏证据；没有执行就写 `PENDING` 或 `N/A + 原因`，禁止默认为通过。
- 只有 `AUT-*` 全部通过才能称为“构建验收通过”。
- 只有相关 `MAN-*` 通过，才能在 Release 说明中声称“Windows 实测”“游戏实测”“真机实测”或“回滚实测”。
- 人工验收全程先用 Mock、保持未武装；游戏数据验证不得依赖人体感觉。真机项不是每个代码版本的发布前置，但未执行时必须明确写出。

## 自动门禁

| ID | 阶段 | 验收项 | 通过标准 | 证据 | 阻断发布 |
| --- | --- | --- | --- | --- | --- |
| AUT-01 | 源码 | 版本一致性 | `VERSION`、Python `__version__`、Lua `VERSION` 相同且为 SemVer | 校验器输出 | 是 |
| AUT-02 | 源码 | 完整回归测试 | `unittest discover` 返回 0 | 测试数量与最终 `OK` | 是 |
| AUT-03 | 源码 | 前端语法 | `node --check` 返回 0 | 校验器输出 | 是 |
| AUT-04 | 隐私 | Git 跟踪清单 | 不跟踪真实配置、日志、`ref/`、构建目录或转储 | `git ls-files` 审计 | 是 |
| AUT-05 | 文档 | 必需文档 | README、安全、第三方、变更、桌面、Hook、更新/回滚、验收矩阵均存在 | 文件清单 | 是 |
| AUT-06 | 构建 | Fluent EXE | 文件存在、体积合理、PE 头为 `MZ` | 文件名与字节数 | 是 |
| AUT-07 | 构建 | 游戏桥 ZIP | ZIP 可读取，含 manifest、`data/*.patch_0`，`Options[].Include=["data"]` | ZIP 结构检查 | 是 |
| AUT-08 | 构建 | 发布文档 | 发布目录含桌面、Hook、更新/回滚、验收矩阵及 Release Notes | 文件清单 | 是 |
| AUT-09 | 完整性 | SHA-256 | `SHA256SUMS.txt` 覆盖所有应发布资产且哈希完全匹配 | 哈希复算 | 是 |

## 人工验收

| ID | 环境 | 验收项 | 步骤摘要 | 必需证据 | 未通过处理 |
| --- | --- | --- | --- | --- | --- |
| MAN-01 | Windows 10/11 + WebView2 | Fluent 启动/退出 | 启动 EXE、切换页面、正常关闭并确认进程退出 | Windows 版本、WebView2 版本、结果 | 阻断“Windows 实测”声明 |
| MAN-02 | Windows 桌面 | F11/F12 全局热键 | 窗口失焦时验证 F11 暂停/恢复；F12 急停并解除武装 | 热键状态变化记录，不含私人桌面截图 | 阻断热键修复声明 |
| MAN-03 | Fluent 桌面 | 启动检查向导 | 冷启动查看向导；确认未自动连接、未开始检测、未武装 | 初始状态文字记录 | 阻断向导安全声明 |
| MAN-04 | Mock | 规则与安全层 | 合成连续伤害，核对固定窗口；分别调整 A/B；验证上限和急停 | 脱敏事件/输出摘要 | 阻断对应功能声明 |
| MAN-05 | 游戏 + 桥（未武装） | 模式阶梯 | 按 `safe → net → menu → recon → live` 逐级重启验证 | 游戏/桥版本、每级 STATUS 摘要 | 阻断桥兼容声明 |
| MAN-06 | 受支持游戏构建（未武装） | 游戏状态准确性 | 对照血量、六肢、阵亡、复活；桥断流后缓存必须失效 | 游戏构建、桥版本、脱敏对照表 | 阻断“游戏实测”声明 |
| MAN-07 | 合格验收者 + 真机 | 设备链路与急停 | 完成禁忌检查后，从最低强度短时测试 A/B 和 App/设备端急停 | 设备代际、App 版本、结果；不得上传配对资料 | 不阻断纯软件发布，但禁止真机声明 |
| MAN-08 | Windows + 上一稳定版 | 回滚 | 按更新文档恢复上一版桌面及对应桥，先以 Mock 启动 | 起止版本、结果、配置兼容备注 | 阻断“回滚实测”声明 |

## 执行命令

源码阶段：

```powershell
./.venv/Scripts/python.exe tools/release_acceptance.py
```

构建并生成 `SHA256SUMS.txt` 后：

```powershell
./.venv/Scripts/python.exe tools/release_acceptance.py `
  --dist dist/<VERSION> `
  --report dist/<VERSION>/RELEASE-ACCEPTANCE.md
```

命令返回 0 只表示自动门禁通过。生成报告中的人工行默认都是 `PENDING`，由验收者在发布说明或外部验收记录中填写；不要修改工具使其自动伪造人工通过。

## 发布记录模板

```text
版本：
提交：
验收时间（含时区）：
自动门禁：PASS / FAIL（附 RELEASE-ACCEPTANCE.md）
MAN-01..08：PASS / FAIL / PENDING / N/A（逐项给出脱敏证据或原因）
已知限制：
回滚目标版本：
验收人：
```

## 隐私要求

不得把以下内容放入验收证据、提交或 Release：真实 `config.json`、二维码、配对/会话 URL、局域网 IP、完整日志、用户名绝对路径、个人桌面截图、内存转储、游戏安装清单。只保留版本、公开资产哈希、脱敏状态摘要和可复现步骤。详见 [更新与回滚](UPGRADE.md) 与仓库 README 的隐私说明。
